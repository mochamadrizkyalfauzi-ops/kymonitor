Fokus & Solusi

Mengapa KYMONITOR Diperlukan?

Fluktuasi suhu dan kelembapan yang tidak terpantau sering kali menjadi pemicu utama kerusakan pada infrastruktur sensitif, seperti ruang server (data center), ruang penyimpanan obat, hingga budidaya agrikultur tertutup.

KYMONITOR hadir untuk memangkas celah tersebut dengan menyediakan sistem monitoring hulu-ke-hilir (end-to-end) yang andal. Sistem ini mengubah pembacaan parameter fisik lingkungan menjadi informasi digital yang dapat diakses dari mana saja, kapan saja, secara instan tanpa perlu memuat ulang halaman (*zero-refresh dashboard*).

Arsitektur Aliran Data (System Blueprint)

1. Edge Sensing Sensor DHT22 membaca parameter termal lingkungan nyata secara periodik.
2. Data Processing NodeMCU ESP8266 mengolah data mentah dan mentransmisikannya via Wi-Fi.
3. Cloud Brokerage Firebase Realtime DB menyimpan data NoSQL dan menyebarkannya secara instan.
4. Analytics Display Web Client menangkap perubahan data, menggambar grafik, dan memvalidasi bug.

Metrik Kapabilitas Sistem

Ultra-Low Latency

Pengantaran data dari sensor fisik hingga muncul di grafik web memakan waktu kurang dari 1 detik (kurang dari 1s).

99.9% Validated Logs

Dilengkapi filter validasi pintar untuk mendeteksi dan membuang data palsu akibat gangguan interferensi sinyal hardware.

Portable Open Data

Mendukung ekspor riwayat log data ke dalam format .csv standar industri agar dapat diolah di Microsoft Excel atau SPSS.

Perangkat Keras

  • Core SoC MCU: NodeMCU ESP8266 Lolin v3
  • Sensor Module: DHT22 (Toleransi ±0.5°C / ±2%)
  • Bandwidth Jaringan: Wi-Fi 2.4 GHz IEEE 802.11 b/g/n

Software & Ekosistem Layanan

  • Antarmuka Web: Tailwind CSS (Responsive Framework)
  • Rendering Grafik: Chart.js Engine (HTML5 Canvas)
  • Layanan Cloud: Firebase Realtime Cloud Database NoSQL
